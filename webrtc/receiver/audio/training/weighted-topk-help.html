Overview & flow

1) Train on mic/file/folder → collect per-class stats (EMA + mean).
2) Recompute Weights → keep Top-K, normalize → Active model weights.
3) Quiet Calibrate → set thr_on/off from quiet fused scores.
4) Detect → fuse class EMAs with active weights, apply penalties, smooth, hysteresis.

Signal framing & rate

  • Sample Rate (target Hz) – Resample to this rate before inference (keep 16 kHz for YAMNet).
  • Frame length (s) – Analysis window; snapped to 0.975s for YAMNet compatibility.
  • Hop (s) – Step between frames; also the timebase for EMAs and charts.
  • Max results from MP – How many classes YAMNet returns (task is cached until recreated).

Smoothing & alerting

  • Per-class EMA τ – Smooth each class score before fusion (detection & quiet cal).
  • Fused score EMA τ – Smooth the final fused score (detection & quiet cal).
  • Min ON hold (ms) – Keep alert ON for at least this long to avoid flicker.

Calibration & thresholds

  • Quiet calibration (s) – Duration to capture quiet fused scores and set thresholds.
  • OFF delta – Hysteresis gap; thr_on = thr_off + delta.

Implementation detail: thr_off = min(0.95, p99 + 0.02) from quiet fused scores; then thr_on = thr_off + delta. Values are saved per model in localStorage and loaded during detection.

Class selection & model training

  • Top-K classes – Keep K non-ignored classes when forming the normalized weights.
  • Hybrid prior (kPrior) – Blend mean vs EMA when data is sparse: 
    λ = kPrior / (kPrior + n)
hybrid = (1−λ)·mean + λ·ema
  • Hybrid half-life (s) – EMA time constant used while accumulating training stats.

Ignore & penalties

  • Ignore classes (training) – Tokens to exclude from stats and Top-K (case-insensitive substring).
  • Penalty map (inference) – Token → negative weight applied to fused score for matching classes.

Buttons and when settings apply

  • Start Training – Uses framing/rate, ignores, and training EMAs; updates preview weights continuously.
  • Recompute Weights – Applies Top-K / kPrior / half-life to freeze the new Active weights.
  • Quiet Calibrate – Uses detection path smoothing to set thresholds for later detection.
  • Start Detect – Uses Active weights, penalties, smoothing + hysteresis.

Cheat-sheet

  • SR_TARGET, FRAME_LEN_S (snapped), HOP_S, MAX_RESULTS → Training & Detection
  • CLASS_EMA_TAU_S, FUSED_EMA_TAU_S, ALERT_HOLD_MS → Detection (+ quiet cal)
  • CAL_SEC, ALERT_OFF_DELTA → Quiet cal (and delta used as fallback in detection)
  • TOP_K, K_PRIOR, HALF_LIFE_S → Training (then used by detection once recomputed)
  • IGNORE_CLASSES → Training (& UI); PENALTY_MAP → Detection

Tip: Train 20–60s per condition, then Recompute Weights, then Quiet Calibrate, then Detect.
